# Hidden Recipes example datapack

Six complete, working `hidden_recipes` examples. Copy this whole folder into a world's `datapacks/` directory
(or your pack's `datapacks/` source) to try them, then run `/reload` or restart the world.

- `enchanted_golden_apple_secret` — requires a "lore fragment" (crafted from paper,
  feather, and ink sac) in inventory.
- `gilded_blackstone_secret` — requires the `minecraft:nether/root` advancement.
- `name_tag_secret` — requires `minecraft:husbandry/tame_an_animal` and not already
  holding a name tag.
- `saddle_secret` — requires either `minecraft:husbandry/tame_an_animal` or
  `minecraft:adventure/adventuring_time`.
- `totem_of_undying_secret` — requires holding a nether star and the
  `minecraft:end/kill_dragon` advancement.
- `smelted_leather_secret` — requires `minecraft:adventure/kill_a_mob`.

See the main [README](../../README.md) for how to write your own hidden-recipe entries.
